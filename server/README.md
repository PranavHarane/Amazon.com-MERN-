Amazon.com Clone - Backend

Backend API for the Amazon.com Clone built using Node.js, Express.js, and MongoDB. This server handles authentication, product management, cart operations, order processing, and user management.

🚀 Features
        RESTful API Architecture
        User Authentication & Authorization
        JWT-Based Authentication
        HTTP-Only Cookie Support
        Product Management
        Cart Management
        Order Processing
        Search Functionality
        MongoDB Integration
        Error Handling Middleware
        Protected Routes
        Environment-Based Configuration

🛠️ Tech Stack
        Node.js
        Express.js
        MongoDB
        Mongoose
        JWT (JSON Web Tokens)
        bcrypt.js
        Cookie Parser
        CORS
        dotenv
